3. PRODUCTION CROSS-ORIGIN & SECURITY SPECIFICATIONS
================================================================================
1. HTTPS & Cookie Security:
   - In production (`NODE_ENV=production`), authentication cookies are issued with:
     * `secure: true` (Transmitted only over HTTPS)
     * `sameSite: 'none'` (Enables cross-origin cookie sharing between Render frontend and backend domains)
     * `httpOnly: true` (Blocks client-side XSS script access to tokens)
2. CORS Allowed Origins:
   - Backend `app.js` CORS middleware permits `https://vendor-os-frontend-xlqx.onrender.com` with `credentials: true`.
3. Tenant Isolation Guard:
   - Requests include `x-business-id` header or rely on the authenticated session's active store context.

6. TROUBLESHOOTING COMMON PRODUCTION ISSUES
================================================================================

1. Issue: "Network Error" or Failed API calls on Production Frontend
   - Cause: `VITE_API_URL` environment variable is either unset or pointing to `localhost`.
   - Fix: In Render Dashboard for the Frontend Static Site, set `VITE_API_URL` to your live Backend URL (e.g. `https://your-backend.onrender.com`) and trigger a manual redeploy.

2. Issue: User logged out immediately or Session not persisting across refreshes
   - Cause: Cross-site cookie blocked due to missing `sameSite: 'none'` and `secure: true` in production.
   - Fix: Ensure `NODE_ENV=production` is set in Render Backend environment variables.

3. Issue: Free Tier Render Backend Cold Start Latency
   - Cause: Free instances spin down after 15 minutes of inactivity. First request takes 30-50s to wake up.
   - Fix: Upgrade to Render Starter plan or configure an uptime monitor ping to keep service warm.

4. Issue: Browser showing old UI / stale version
   - Cause: Browser caching bundled JS/CSS assets.
   - Fix: Perform Hard Reload (`Ctrl + Shift + R`) or clear site data in DevTools.
