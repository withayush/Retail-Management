                     VENDOROS - COMPLETE BACKEND API LIST & TESTING GUIDE
================================================================================
Base URL: http://localhost:3001
Content-Type: application/json

Is file me Backend ki saari APIs, unka kaam (Purpose), Headers, Testing ke liye 
Ready-to-use Dummy Data (JSON / Params) or Expected Response format diya gaya hai.

--------------------------------------------------------------------------------
AUTHENTICATION & HEADERS OVERVIEW:
--------------------------------------------------------------------------------
1. Public APIs (Register, Login, Verify OTP): Kisi token ki zaroorat nahi hoti.
2. Protected APIs: 
   - Header: "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
   - Ya phir browser/Postman me "accessToken" cookie automatically send hoti hai.
3. Multi-Tenant Business APIs (Categories, Products, Active Context):
   - Header: "x-business-id: <BUSINESS_ID>" (Optional agar user ke paas ek hi business hai, system auto-select kar leta hai).

MODULE 2: AUTHENTICATION & USER MANAGEMENT (/api/auth)
================================================================================

2.1 REGISTER NEW USER
--------------------------------------------------
Method:      POST
Endpoint:    /api/auth/register
Description: Naya vendor/retailer account create karta hai aur phone number verify 
             karne ke liye 6-digit OTP generate karta hai.
Auth:        None

Request Headers:
  Content-Type: application/json

Dummy Request Body:
{
  "fullName": "Ayush Sharma",
  "email": "ayush.sharma@example.com",
  "phone": "+919876543210",
  "password": "Password@123"
}

Validation Rules:
- fullName: min 2 characters
- email: valid email format
- phone: valid 10-digit Indian number (+91 optional)
- password: min 8 chars (1 uppercase, 1 lowercase, 1 number, 1 special character)

Dummy Response (201 Created):
{
  "success": true,
  "message": "Registration successful. Verification OTP generated.",
  "data": {
    "accountId": "65f1a2b3c4d5e6f7a8b9c0d1",
    "phone": "+919876543210",
    "otp": "123456"
  }
}
