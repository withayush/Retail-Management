[✓] C15. T22: Low-Stock Limit Notifications & Deterministic Alerts Queue Engine (`/api/inventory/alerts`)
    - Purpose & Core Rule: "Deterministic engine checking items falling below defined ReorderLevel. Sends low-stock triggers to alerts queue with zero duplicate spamming."
    - Deterministic Rule Engine ($Input \to Deterministic Output$):
      * $\text{IF availableStock} \le \text{reorderLevel} \implies \text{Trigger / Update Alert}$
      * $\text{IF availableStock} > \text{reorderLevel} \implies \text{Auto-Resolve Active Alert}$
    - Severity Differentiation:
      * `availableStock <= 0` $\implies$ `CRITICAL (OUT_OF_STOCK)`
      * `availableStock <= reorderLevel` $\implies$ `WARNING (LOW_STOCK)`
      * Computes exact shortage deficit: `deficitQty = reorderLevel - availableStock`.
    - Zero Duplicate Spamming (Deduplication Guarantee):
      * Consecutive stock deductions update existing `UNREAD`/`ACKNOWLEDGED` alert's `currentStock`, `deficitQty`, and `severity` rather than creating duplicate rows.
    - Replenishment Auto-Resolution:
      * Stock In or physical adjustment bringing stock above threshold automatically sets `status: 'RESOLVED'` and records `resolvedAt`.
    - Alert Queue APIs:
