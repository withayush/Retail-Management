================================================================================
                     VENDOROS - COMPLETE BACKEND API LIST & TESTING GUIDE
================================================================================
Base URL: http://localhost:3001
Content-Type: application/json

Is file me Backend ki saari APIs, unka exact purpose, required headers, Mongoose 
Models ke exact schema ke anusaar accurate Dummy Request Bodies aur actual MongoDB 
Database Response structures diye gaye hain.

--------------------------------------------------------------------------------
AUTHENTICATION & HEADERS OVERVIEW:
--------------------------------------------------------------------------------
1. Public APIs (Register, Login, Verify OTP, Resend OTP):
   - Headers: "Content-Type: application/json"
   - No token required.

2. Protected APIs (User Profile, Business Creation/Onboarding):
   - Header: "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
   - (Browser / Postman me "accessToken" cookie automatically send ho sakti hai).

3. Multi-Tenant Business APIs (Categories, Products, Inventory, Sales, Payments, Customers, Suppliers):
   - Header: "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
   - Header: "x-business-id: <BUSINESS_ID>" (Optional: agar user ke paas ek hi active business hai, system auto-select kar leta hai).
